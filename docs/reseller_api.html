Reseller API v1

Integra el catálogo oficial de Francho Shop, recargas directas en juegos, tarjetas de regalo, suscripciones digitales y recepción de códigos SMS en tu servidor, bot o tienda web.

Base URL https://franchoshop.com/v1
FormatoJSON estándar UTF-8 sobre HTTPS.
MonedaTodos los precios y saldos se manejan en USDT.
Entrega InmediataLas compras descuentan saldo y se procesan en tiempo real.
La clave API debe custodiarse exclusivamente en tu servidor backend. Nunca la expongas en JavaScript frontend, aplicaciones cliente distribuidas ni repositorios públicos.

Inicio rápido

Comprueba tu saldo y conexión enviando tu clave de revendedor:

cURL
curl "https://franchoshop.com/v1/wallet" \
  -H "Authorization: Bearer fs_live_TU_CLAVE"
Node.js / JavaScript
const res = await fetch("https://franchoshop.com/v1/wallet", {
  headers: { "Authorization": "Bearer fs_live_TU_CLAVE" }
});
const wallet = await res.json();
console.log("Saldo disponible:", wallet.data.available, "USDT");
Python
import requests

res = requests.get(
    "https://franchoshop.com/v1/wallet",
    headers={"Authorization": "Bearer fs_live_TU_CLAVE"},
    timeout=15
)
data = res.json()["data"]
print(f"Saldo: {data['available']} USDT")

Autenticación

Cada petición debe incluir tu clave en uno de los siguientes encabezados HTTP:

Bearer (Recomendado)
Authorization: Bearer fs_live_TU_CLAVE
X-API-Key
X-API-Key: fs_live_TU_CLAVE

Idempotencia

Para prevenir cobros duplicados en caso de desconexión o reintentos automáticos de tu cliente, envía el encabezado opcional Idempotency-Key:

Encabezado
Idempotency-Key: mi-orden-20261013-0001
Si una petición se interrumpe y la reintentas con el mismo identificador, Francho Shop responderá con la orden original ya registrada sin generar un segundo débito de saldo. Si no envías el encabezado, el sistema genera automáticamente un identificador seguro.

Pedidos y Recargas

POST/orders

Crear Pedido / Recarga Directa

Debita el saldo de tu cuenta y ejecuta la recarga o entrega digital en tiempo real.

CampoTipoDescripción
product_idstringCódigo del producto obtenido del catálogo (ej: free_fire_latam). Obligatorio.
offer_idstringCódigo de la oferta deseada (ej: 110_diamonds). Obligatorio.
quantityintCantidad a adquirir (por defecto 1).
fieldsobjectDiccionario con los datos requeridos por la oferta (ej: {"player_id": "123456789"}).
cURL
curl -X POST "https://franchoshop.com/v1/orders" \
  -H "Authorization: Bearer fs_live_TU_CLAVE" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: mi-orden-20261013-0001" \
  -d '{
    "product_id": "free_fire_latam",
    "offer_id": "110_diamonds",
    "quantity": 1,
    "fields": {
      "player_id": "123456789"
    }
  }'

Números Virtuales (SMS para Verificaciones)

Adquiere números virtuales temporales en más de 180 países para recibir códigos de activación en WhatsApp, Telegram, Google, TikTok, Discord, etc.

👑 Oro VIP (≥ $100)Margen +7% (precio mín. $0.40)
🥈 Plata (≥ $50)Margen +10% (precio mín. $0.50)
🥉 Bronce (≥ $25)Margen +14% (precio mín. $0.60)
Reglas de Reembolso: Si transcurren 20 minutos sin llegar ningún SMS, la orden expira y se reembolsa el 100% automáticamente. Si transcurren 120 segundos (2 minutos) sin recibir SMS, puedes cancelarla manualmente con reembolso inmediato.

Consultar Código SMS

Sincroniza en tiempo real. Cuando el código llega, el campo sms_code contiene el código de verificación.

Estados de Pedido

completed · Completado y entregado
processing · En proceso con la red
refunded · Rechazado o cancelado (100% reembolsado)

Errores HTTP

CódigoSignificadoSolución
400Parámetros o datos inválidosVerifica que todos los campos requeridos en fields estén presentes.
401No autorizadoClave ausente, revocada o inválida. Revisa tu encabezado de autorización.
404No encontradoEl product_id u offer_id no existe.
422Error de validaciónIdempotency-Key debe tener entre 8 y 128 caracteres.
502Error de entregaLa recarga fue rechazada por la red central; el saldo se reembolsa al instante.

Seguridad y Buenas Prácticas

  • Utiliza variables de entorno seguras para guardar tu clave API en tu servidor backend.
  • Usa Idempotency-Key en solicitudes de compra para asegurar reintentos limpios ante interrupciones de red.
  • Comprueba siempre el código HTTP de respuesta antes de procesar el cuerpo JSON.
  • Si detectas cualquier anomalía con una clave, revócala y rota una nueva desde el panel de revendedores.
