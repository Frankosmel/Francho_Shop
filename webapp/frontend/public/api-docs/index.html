Documentación Oficial de API Francho Shop

Automatiza compras de diamantes Free Fire, Robux, gift cards y activación de números SMS en tu propia tienda o bot.

🔑 Autenticación

Todas las solicitudes a la API deben incluir tu clave secreta de API en el encabezado HTTP X-API-Key o mediante Bearer token.

Authorization: Bearer TU_API_KEY_AQUI
Content-Type: application/json

📡 Endpoints Principales

GET https://franchoshop.com/api/v2/balance

Consulta tu saldo disponible en CUP y USDT.

GET https://franchoshop.com/api/v2/catalog

Obtiene la lista de juegos disponibles, paquetes, precios y campos requeridos (Player ID, Región, etc.).

POST https://franchoshop.com/api/v2/orders/create

Crea una recarga automática por ID. Se descuenta de tu saldo y se procesa en segundos.

GET https://franchoshop.com/api/v2/orders/{order_id}

Consulta el estado en tiempo real (completed, processing, failed) de una recarga.
